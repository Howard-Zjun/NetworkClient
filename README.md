# NetworkClient

Java 课程完结项目：一个基于 Swing 和 UDP 组播的局域网聊天客户端。客户端加入同一组播地址 `239.1.2.4:8080` 后，可在局域网内交换消息，无需中心服务器。

## 主要功能

- **图形化聊天界面**：提供 Swing 登录与聊天窗口，包含昵称输入、头像选择、消息输入和聊天记录展示。
- **局域网文本群聊**：通过 UDP 组播发送与接收文本消息，将收到的内容展示为聊天消息行。
- **图片消息接收与展示**：接收图片消息并反序列化，在聊天界面展示图片内容。
- **本地图片预览**：通过图片选择入口选择 JPG、PNG 图片，在本地聊天界面预览。

## 核心模块

- **`LoginView` / `ChatView`**：界面层，负责登录信息输入、聊天窗口、消息发送入口及接收消息的界面展示。
- **`NetworkPost`**：网络收发基础层，创建并加入组播连接，封装文本、登录和退出消息的发送；接收接口由聊天界面中的实现负责处理。
- **`NetworkManage`**：用户信息管理，按用户 ID 保存、查询和移除用户对象，供消息展示与用户列表处理使用。
- **`MessageAbstract` 及其子类**：消息模型，保存发送者信息，通过 `TextModel`、`ImageModel`、`LoginModel` 和 `QuitModel` 等类型区分消息内容。
- **`Translate`**：消息转换工具，通过 Java 对象序列化与反序列化，在消息对象和网络传输字节之间转换。
- **`Row` / `TextRow` / `ImageRow`**：聊天消息组件，组织文字和图片消息的展示。
- **`Collector`**：集中保存当前用户信息、组播地址及界面展示参数。

## 已预留但尚未完成

- **图片发送**：选图后仅在本地预览，尚未将图片封装为 `ImageModel` 并发送。
- **私聊**：已预留相关模型、网络类型和用户列表双击入口，尚未实现定向发送与独立会话。
- **在线用户同步**：登录广播与远端在线用户列表同步尚未完整接通，退出时的列表移除逻辑仍需修正。

当前不支持语音消息、通用文件传输、身份认证、可靠传输或服务端转发。
