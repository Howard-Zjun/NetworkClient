# NetworkClient

Java 课程完结项目：一个基于 UDP 组播的局域网聊天服务。客户端加入同一组播地址 `239.1.2.4:8080` 后，可在局域网内交换消息，无需中心服务器。

## 已支持

- Swing 图形化登录与聊天界面。
- 昵称输入与头像选择控件。
- 基于 UDP 组播的局域网文本群聊。
- 文本消息的发送、接收与聊天记录展示。
- 图片消息的接收、反序列化与聊天界面展示。
- 选择 JPG、PNG 图片并在本地聊天界面预览。

## 已预留但尚未完成

- 当前客户端尚未提供图片发送入口：选图后仅本地预览，未将图片封装为 `ImageModel` 后发送。
- 私聊相关模型、网络类型和用户列表双击入口已预留，但没有定向发送或独立会话实现。
- 登录广播与远端在线用户列表同步尚未完整接通；退出用户列表移除逻辑也需要修正。
- 不支持语音消息、通用文件传输、身份认证、可靠传输或服务端转发。
