# NetworkClient

Java 课程完结项目。

## 已支持

- Swing 图形化登录与聊天界面。
- 昵称输入与头像选择控件。
- 基于 UDP 组播的局域网文本群聊（组播地址：`239.1.2.4:8080`）。
- 文本消息的发送、接收与聊天记录展示。
- 本地用户列表及退出消息发送、接收处理。
- 选择 JPG、PNG 图片并在本地聊天界面预览。

## 已预留但尚未完成

- 图片消息模型及接收展示分支已存在，但图片尚未通过网络发送。
- 私聊相关模型、网络类型和用户列表双击入口已预留，但没有定向发送或独立会话实现。
- 登录广播与远端在线用户列表同步尚未完整接通。
- 不支持语音消息、文件传输、身份认证、可靠传输或服务端转发。
